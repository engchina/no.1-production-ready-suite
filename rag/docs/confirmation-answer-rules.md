# 回答の規則（回答プロンプトの役割の文）

管理者が回答の規則（「この種類の質問には画面 A を案内する」「原因は言い切らず可能性にとどめる」「A と B を区別する」など）を
足すときは、取込・検索・回答設定 > 回答プロンプトの「役割と回答の書き方」（`generation.role`）に書きます。この文は
すべての回答の生成に渡り、資料の根拠にはなりません。信頼の境界・引用・出力の形の固定の部分はコードが必ず足すので、
役割の文に書き直す必要はありません。

検索・回答プロファイルごとの指示は、プロファイルの編集の「追加の指示」に書きます（#5848）。

- **回答の指示に足す文**: そのプロファイルの回答の生成で、上の役割の文の後に足します。役割の文と固定の部分は
  置き換えられず、固定の部分と食い違う指示は効きません。検索には使いません。
- **質問に足す文**: そのプロファイルのすべての質問の末尾に足し、検索と回答の両方に使います（用語・同義語の照合の後。
  安全チェック・履歴による補完・雑談の判定・業務ガイドと登録済みQ&Aの照合は利用者の質問のまま）。検索の結果も
  変わるので、回答の書き方だけを変えたいときは「回答の指示に足す文」を使います。

どちらもプロファイルのすべての質問に同じ文を足します。検索・回答プロファイルごとに規則を登録して質問に照合する層
（回答前の確認・回答への差し込み）は持ちません（#4799）。
質問で決まらない条件を利用者に確かめるときは、業務ガイドの条件（確認の質問と選択肢）を使います。登録した
用語・同義語は検索文の追加と回答の補助に使い、規則ではありません。
