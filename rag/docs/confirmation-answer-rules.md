# 回答の規則（回答プロンプトの役割の文）

管理者が回答の規則（「この種類の質問には画面 A を案内する」「原因は言い切らず可能性にとどめる」「A と B を区別する」など）を
足すときは、取込・検索・回答設定 > 回答プロンプトの「役割と回答の書き方」（`generation.role`）に書きます。この文は
すべての回答の生成に渡り、資料の根拠にはなりません。信頼の境界・引用・出力の形の固定の部分はコードが必ず足すので、
役割の文に書き直す必要はありません。

検索・回答プロファイルごとに規則を登録して質問に照合する層（回答前の確認・回答への差し込み）は持ちません（#4799）。
質問で決まらない条件を利用者に確かめるときは、業務ガイドの条件（確認の質問と選択肢）を使います。登録した
用語・同義語は検索文の追加と回答の補助に使い、規則ではありません。
