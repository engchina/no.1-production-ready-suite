# 画像解析の用途

全体の既定は「実データ・記録」。文書レシピで「画面例・説明用」へ上書きでき、上書きしなければ全体の既定を継承する。ナレッジベースや検索・回答プロファイルの設定ではない。

用途は解析開始時の実効設定に固定し、画像読取の入力と解析成果物へ保存する。用途の異なる解析は抽出版と画像応答checkpointを共有しない。同じ入力・用途の有効なcheckpointは再利用する。後の全体設定の変更で、保存済み解析の用途を読み替えない。変更を反映するには明示的な再解析が必要。

`record` は対象と記録時点に限る資料の値であり、現在の状態・未記載の条件・質問への適合を保証しない。`example` は例示の値を実際の対象値にせず、読める操作部品・位置・操作条件は保持する。過去に用途が無い場合は未記録とし、現在の既定で補わない。原生の本文や表全体へ画像用途を広げない。

## 保存した画像読取方針

組み込み方針はcallerが渡す用途を参照する。保存した `picture_description.rules` は従来どおり優先し、旧画像テンプレートのmanaged規則も逐字保持する。自動で新方針へ置換しない。

そのため、旧「画面の値は原則例示」の方針を保存している場合、新しい用途設定と両立するとは言えない。任意の独自方針についても、コードが語句から意味互換性を判定することはない。実効方針の確認・扱いが決まるまで、保存方針のある全環境で用途制御が働くとは約束しない。既存設定や言語資源をこの機能が書き換えることはない。

## この段階の範囲

ここで有効にするのは、画像解析の設定・版固定・読取方針・保存まで。後続の全分割方式への用途伝播、回答生成・監査の用途消費、原文の用途注記は別の統合項目。画像の正確な認読、操作可能性、最終回答の意味品質を型や保存用途だけで保証しない。
