# 生成前と生成後の根拠不足への補救

生成の後に LLM の確認の段は持たず（#4714）、生成が明示した gap をそのまま回答の不足として返す。確かめるのは参照の実在と形式だけである。

検索語の一致や関連する引用元の存在だけで、材料の十分性を確定しない。回答の充足と材料の有無を別のフィールドにすることで、誤った対処を追跡できる。

追加の検索は既存の `ExtraRetrievalBudget` を使う。`CoverageUsage` は実行した検索文、追加根拠、追加の検索に使った時間を後続へ引き継ぐ。初回検索は追加検索として数えない。章節の原文読取は従来の章節読取予算と回答全体の期限に従う。総入力予算・各段の上限のさらなる整理は #3682 に残る。
