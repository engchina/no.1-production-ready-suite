# 検索の段階別予算と比較（#3682）

## 契約と互換性

検索範囲（権限・KB・基準日・active artifact）を確定し、各検索文の hybrid 検索、RRF、候補選択、Rerank、起点選択、原文の読取、回答入力の予算の順で適用する。KB の membership と文書レシピの成果物を変更しない。

| 段 | 全体設定 | 初期値・根拠 |
|---|---|---|
| 検索文ごとの各検索経路の取得 | `RAG_RETRIEVAL_QUERY_LIMIT` | 600。従来の既定の `max(candidate_limit, RAG_CANDIDATE_DIVERSITY_DEPTH)` と、既定 top_k=50 の結果を維持 |
| RRF 順の基本候補 | `RAG_RETRIEVAL_CANDIDATE_LIMIT` | 150。従来の `min(150,max(50,top_k*8))` の top_k=50 における結果を維持。今後は top_k で増減しない |
| 多様化を探す融合順位の深さ・追加枠 | 既存 `RAG_CANDIDATE_DIVERSITY_*` | 保存済みの値を維持。取得深度を変更する設定とは分離 |
| 全拡張を含む Rerank 入力 | `RAG_RERANK_CANDIDATE_LIMIT` | 0 は有効な各段の既存上限の和から互換上限を導出。正数は比較用の明示的な総上限 |
| 回答起点 | `top_k` / 省略時 `RAG_SEARCH_TOP_K_DEFAULT` | 既存の50を維持。親へ集約した原文は1枠とし、同じ親の子の引用位置を追加しても次の原文の枠を消費しない |
| 回答本文 | 既存の record・文字・モデル入力予算 | 変更しない。採用前の取得と、モデルへ渡す原文を区別 |

600・150 は測定した最適値ではない。従来 top_k が小さい呼出では候補数も暗黙に減っていたため、その呼出では今回の取得幅が広くなる。従来多様化の深度を個別設定していた環境は、移行時に新しい取得上限も同じ値へ明示する。

基本150 + 多様化100 + 有効な明示参照4 の小計は **254**。既定で有効な条目録の (16候補文書+2範囲文書)×(8初選+6追加選択)=252 を加え、既定の総枠は **506**。条目録を無効にすれば254になる。実体・文書構造・画面も有効な場合だけ既存の上限を加える。適用する成果物のない段は枠を予約するだけで、実際の採用件数は0（効果の測定対象には数えない）。画面は既存の3画面×10箇所、条目録は既存の文書数と文書ごとの選択数・追加選択数の積。添付は呼出元の既存制約で今回選ばれた明示入力数だけを加える。各経路の admission と合計上限を両方適用し、未知の経路は枠を持たない。OCI の API の最大容量から推奨値は導かない。

同じ chunk ID、および同じ文書・成果物・抽出元 ID・本文の重複だけを候補予算の前にまとめる。別版・レシピ・文書の同文、出所が不明な同文、別ページの繰り返しは統合しない。

原文読取は精排後の起点から行う。親子方式は保存済み親本文、その他は命中と同じ成果物の近傍（#3681）。既読の範囲は回答内で再利用する。明示参照先の本文など精排に必要な情報は前もって読む。原文の読取に失敗したときは成功扱いせず既存の失敗経路へ伝える。

## 観測

回答の記録の `diagnostics.retrieval_stages` は各検索ごとに、融合順位・候補から外した ID と理由、Rerank の入力と出力、総上限の導出に使った各段の上限、起点、読んだ原文、回答文脈へ採った原文と文字予算による除外を順番に記録する。語の命中率や候補件数を「回答に十分」の判定に読み替えない。追加検索は #3675 の要求追跡と既存の ExtraRetrievalBudget・期限・キャッシュを使い、新しい根拠が無ければ再生成しない。

## 同一条件の比較

新しい実モデル実験 runner は作らず、#2573 の段階除去と既存の品質評価を使う。設定ごとに同じ合成ケース・索引・artifact・scope・モデル・採点版を固定して実行し、記録の `retrieval_stages` を比較する。

| 対照 | 変更する設定だけ | 判断対象 |
|---|---|---|
| 現行互換 | 総枠0、既存の有効段 | 比較の基準 |
| 総枠の比較 | 総枠を明示的に複数設定 | 必要根拠が落ちる段と Rerank の使用量 |
| 多様化なし | 追加枠0、取得上限は同じ | 複数文書への寄与 |
| 文書制御なし | 既存の document selection / anchors per document を無効 | 精排後に必要根拠を後回しにする影響 |
| 各拡張を単独除去 | 参照・実体・構造・画面・条目録・章節を1つずつ OFF | 適用した段だけの条件付き寄与 |

実行には単一文書の複数手順、複数文書比較、親子/非親子、重複、別artifact、明示参照、権限外を含める。各段で必要根拠の ID の残存率/順位を測り、最終回答は正確性・必要事項・引用の支持で評価する。呼出数・使用量・p50/p95・キャッシュ条件・失敗/未完了の分母も残す。機能のための成果物が無いケースを「効果なし」に数えない。

本変更で実施するのは決定論 stub の回帰。実 OCI の品質・費用・時間の AB は未実施。したがって多様化・文書選択・起点上限の既定を、改善したとの主張で削除しない。既定値の最適化と各拡張の採否の確定は、測定結果が揃ってから #3682 / #2573 に記録する。
